# tally の配布物の仕様

**利用者に対する契約。** ここに書いたことは、破ると利用者の導入手順が壊れる。
判断の過程は [ADR-0009](../../../docs/adr/0009-release-distribution.md) にある。

**ここに書くのは「何を保証するか」だけ。**

**書かないもの**:

| 書かないもの | 正しい場所 |
| --- | --- |
| 入手の手順（どう叩くか） | `README.md` |
| **なぜこの形にしたか** | `docs/adr/0009-release-distribution.md` |
| 出力の形式・終了コード | `output-format.md` |
| ワークフローの実装 | `.github/workflows/release.yml` |
| **どの版が出ているか** | GitHub Releases が答える。**ここに書かない** |

## 対応するターゲット

| ターゲット | リンク |
| --- | --- |
| `x86_64-unknown-linux-musl` | **静的。** 共有ライブラリを要求しない |
| `aarch64-apple-darwin` | **システムライブラリのみ**（`/usr/lib`、`/System`） |

**macOS に完全な静的リンクは無い。** `libSystem` は必ず付く。
保証するのは **システム外のライブラリに依存しないこと**である。

**これ以外のターゲットは出さない。** 足すのは後方互換。
**減らすのは破壊的変更**である。

## アーカイブ

| 項目 | 保証 |
| --- | --- |
| 形式 | `tar.gz` |
| ファイル名 | `tally-<版>-<ターゲット>.tar.gz` |
| **展開すると 1 つのディレクトリが出る** | 名前は `tally-<版>-<ターゲット>`。**カレントに散らばらない** |
| checksum | 同名 + `.sha256`。`shasum -a 256` の形式 |

**版に `v` は付かない。** タグは `v0.1.0` だが、アーカイブ名は `tally-0.1.0-...` である。

### 中身

```
tally-<版>-<ターゲット>/
├── tally                  実行ファイル
├── completions/
│   ├── tally.bash
│   ├── _tally             zsh
│   ├── tally.fish
│   └── _tally.ps1         PowerShell
├── man/
│   └── tally.1
├── LICENSE
└── README.md
```

- **補完は 4 シェル。** bash / zsh / fish / PowerShell。
  **`elvish` は出さない**（足すのは後方互換）
- **man は 1 ページ。** `tally.1`（セクション 1）
- **実行ファイルはアーカイブの直下**。`bin/` の下ではない

## 署名と公証

**していない。** そのため **macOS では初回起動が Gatekeeper に止められる。**
利用者が自分で許可する必要がある（手順は `README.md`）。

**これは意図した割り切りである**（ADR-0009 論点 1）。
署名は段階 9 の学習対象ではない。

## 版の付け方

- タグは `v<semver>`。`v0.1.0`、`v0.1.0-rc.1`
- **`-` を含むタグはプレリリース**として公開される
- **タグと `Cargo.toml` の版は必ず一致する。**
  ずれていればリリースは失敗する（ビルドより先に検査する）

### 版が約束すること

**約束の範囲は、この文書と
[`output-format.md`](output-format.md) に書いてあることだけである**
（判断は [ADR-0011](../../../docs/adr/0011-v0-1-0-promise.md)）。

- **破壊的変更では minor を上げる**（`0.1.x` → `0.2.0`）。
  **`0.x` に semver が要求する以上に縛っている** —
  `cargo` の `^0.1` が `0.2` へ上がらない挙動に乗るため
- **patch は後方互換の変更だけ**
- **破壊的変更があるときは、リリースノートにその節を置く。**
  `CHANGELOG.md` は置いていない（上の 2 文書の差分が正本）
