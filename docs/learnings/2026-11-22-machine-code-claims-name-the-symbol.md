# 機械語について書くときは、どの関数の中かをシンボル名で書く

**得た日**: 2026-11-22（本の第 9 章を書いたとき）

## 学び

「`buckets` の機械語は表を引いて呼ぶ」と書いたが、表を引く命令は `buckets` 本体には無く、`map` に渡したクロージャ `buckets::{closure#0}` の中にあった。
イテレータやクロージャを使う関数は、ソースでは 1 つでも、機械語では本体・クロージャ・アダプタの実体に分かれる。
観察した命令列を、ソースの関数名で呼ぶとずれる。

同じ理由で、「`buckets` のシンボルは 1 つ」も言い過ぎだった。`Map<Iter<&dyn Bucket>, ...>` の実体がいくつも並んでいた。
言いたかったのは「型ごとには分かれない」で、「1 つ」ではなかった。

## 改善候補

- 機械語を引用・要約するときは、`nm -C` で見たシンボル名をそのまま書く
- 「1 つ」「2 つ」と数えるときは、何を数えたか（型ごとの実体か、シンボル全部か）を先に決める
