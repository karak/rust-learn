# クロージャを返すクロージャで、`move` と参照の借り直しが要らない場合がある

2026-11-22、本の第 8 章を書いていて観測した。Rust 1.97.1。

`iter().map(|path| { let s = &s; move || ... })` の形は、外側のクロージャの引数を内側に奪わせ、
ほかの変数は参照で渡すための定石である。
**`path` が参照（`iter()` が出す `&T`）なら、2021 年版以降はこの定石が要らない。**
内側のクロージャは変数 `path` ではなくその先（`*path`）を借りるので、外側が返っても借りた先は消えない。
2018 年版では変数 `path` を借りるので `E0373` になる。

`path` を値で受け取る（`iter().cloned()` など）と、`move` が無ければ `E0373`、
`move` だけなら他の変数まで奪おうとして `E0507` になり、借り直しが必要になる。

改善候補: クロージャを返すコードを書くときは、まず `move` 無しで試し、
要るのは外側のクロージャが値で持つ変数を使うときだけかを確かめる。
